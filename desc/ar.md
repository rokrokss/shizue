🌸 Shizue - مساعد التصفح المدعوم بالذكاء الاصطناعي

Shizue هو إضافة Chrome تدمج نماذج اللغة الكبيرة (LLMs) بسلاسة في تصفحك اليومي للويب، مما يحول كيفية تفاعلك مع المحتوى عبر الإنترنت. اختبر قوة الذكاء الاصطناعي مباشرة في متصفحك مع واجهة اللوحة الجانبية البديهية.

✨ الميزات الرئيسية

🌐 الترجمة الذكية ثنائية اللغة
- اقرأ المحتوى بلغتين في وقت واحد مع الترجمة المدعومة بالذكاء الاصطناعي
- مثالي لمتعلمي اللغات ومستهلكي المحتوى الدولي
- يحافظ على السياق والفروق الدقيقة مع فهم LLM المتقدم

🎬 ترجمة تسميات YouTube في الوقت الفعلي
- شاهد مقاطع الفيديو بأي لغة مع ترجمات AI فورية
- تظهر التسميات بشكل طبيعي أثناء المشاهدة
- دعم لعدة لغات مستهدفة

📝 مذكرة الويب
- دون الملاحظات أثناء التصفح
- نظم أفكارك وأفكارك
- ابحث في مذكراتك بسهولة
- الوصول إلى ملاحظاتك عبر جلسات التصفح

💬 مساعد دردشة AI تفاعلي
- اطرح أسئلة حول أي محتوى صفحة ويب
- احصل على ملخصات وشروحات ورؤى فورية
- يدعم نماذج AI متعددة (OpenAI GPT، Claude، Gemini)
- استجابات واعية بالسياق بناءً على الصفحة الحالية

📋 تلخيص الصفحة بنقرة واحدة
- افهم فورًا الأفكار الرئيسية لأي مقال أو صفحة ويب
- وفر الوقت مع ملخصات موجزة مولدة بواسطة AI
- مثالي للبحث وجمع المعلومات السريع

🎯 إجراءات قائمة السياق الذكية
- انقر بزر الماوس الأيمن للترجمة أو الشرح أو تلخيص النص المحدد
- فحص القواعد واقتراحات تحسين الكتابة
- وصول سريع لميزات AI دون مغادرة الصفحة

🎨 ميزات إضافية
- دعم السمة الداكنة/الفاتحة للعرض المريح
- دعم لأكثر من 24 لغة
- اختصارات لوحة مفاتيح قابلة للتخصيص
- تتبع استخدام الرموز لإدارة API

🚀 البدء
1. قم بتثبيت Shizue من متجر Chrome الإلكتروني
2. انقر على أيقونة الإضافة لفتح اللوحة الجانبية
3. أضف مفتاح AI API المفضل لديك (OpenAI أو Anthropic أو Google)
4. ابدأ التصفح بقوى AI الخارقة!

💡 مثالي لـ
- الطلاب والباحثين
- متعلمي اللغات
- منشئي المحتوى والكتاب
- المحترفين الدوليين
- أي شخص يريد التصفح بذكاء أكبر

🔒 الخصوصية والأمان
- يتم تخزين مفاتيح API بأمان في متصفحك
- لا يتم إرسال أي بيانات إلى خوادم طرف ثالث (باستثناء موفري AI المختارين)

حول تجربة التصفح الخاصة بك مع Shizue - حيث يلتقي الذكاء الاصطناعي بالاستخدام اليومي للويب. قم بالتثبيت الآن واكتشف طريقة أذكى لاستكشاف الإنترنت!
