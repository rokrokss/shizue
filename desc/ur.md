🌸 آپ Shizue کے ساتھ Chrome کے سائیڈ پینل میں AI اسسٹنٹ استعمال کر سکتے ہیں۔ صفحہ چھوڑے بغیر چیٹ کریں، جو پڑھ رہے ہیں اس کا خلاصہ ایک کلک میں لیں، اور ویب صفحات اور YouTube ویڈیوز میں اصل متن اور ترجمہ ایک ساتھ دیکھیں۔

Shizue مفت اور اوپن سورس (MIT) ہے۔ یہ آپ کی اپنی API کلید سے چلتا ہے: OpenAI، Anthropic (Claude) یا Google (Gemini) کی کلید، یا OpenRouter کی ایک ہی کلید، جس سے یہ سب اور DeepSeek بھی استعمال ہو سکتے ہیں۔ نہ اکاؤنٹ، نہ سبسکرپشن، اور نہ ہی Shizue کا کوئی سرور۔ آپ اپنے AI فراہم کنندہ کو صرف اتنی ادائیگی کرتے ہیں جتنا استعمال کرتے ہیں۔


✨ خصوصیات

💬 سائیڈ پینل چیٹ
- کسی بھی صفحے پر Ctrl+Shift+E (Mac پر Cmd+Shift+E) سے کھولیں
- تصویریں منسلک کریں، اور پرانی چیٹس تاریخ میں جا کر دوبارہ کھولیں

📋 صفحے کا خلاصہ
- جو صفحہ آپ پڑھ رہے ہیں اس کا ایک کلک میں خلاصہ کریں، پھر اسی چیٹ میں مزید سوال پوچھیں

🌐 دو لسانی ویب صفحات
- ہر پیراگراف کے نیچے اس کا ترجمہ آتا ہے، اور اصل متن اپنی جگہ رہتا ہے

🎬 دو لسانی YouTube کیپشن
- ویڈیو دیکھتے ہوئے کیپشن کا ترجمہ ہوتا جاتا ہے اور اصل لائن کے نیچے دکھایا جاتا ہے
- ترجمے کی زبان اور لائنوں کی تعداد چنیں، اور A یا D دبا کر پچھلے یا اگلے کیپشن پر جائیں

🎯 رائٹ کلک مینو
- منتخب متن: ترجمہ، وضاحت، خلاصہ یا گرامر درست کرنا
- تصویر: اس کی وضاحت یا اس میں لکھا متن نکالنا
- پورا صفحہ: ترجمہ یا خلاصہ

📝 میمو
- لکھتے وقت خود بخود محفوظ ہوتے ہیں، اور انہیں پن بھی کیا جا سکتا ہے اور تلاش بھی

🎨 مزید
- ٹوکن کے استعمال کا چارٹ، جس میں نظر آتا ہے کہ ہر ماڈل نے کتنا استعمال کیا
- لائٹ اور ڈارک تھیم
- 23 زبانوں میں انٹرفیس


🔒 پرائیویسی
- آپ کی API کلیدیں، چیٹ کی تاریخ اور میمو صرف آپ کے براؤزر میں رہتے ہیں
- کسی فیچر کو استعمال کرتے وقت صرف وہی مواد، جس کی اس فیچر کو ضرورت ہو، آپ کے براؤزر سے سیدھا آپ کے منتخب کردہ AI فراہم کنندہ کو بھیجا جاتا ہے
- کوئی اینالیٹکس یا ٹریکنگ نہیں
- سورس کوڈ:
https://github.com/rokrokss/shizue


🚀 شروع کیسے کریں
1. Shizue انسٹال کریں اور سائیڈ پینل کھولنے کے لیے Ctrl+Shift+E (Mac پر Cmd+Shift+E) دبائیں
2. اپنی API کلید پیسٹ کریں۔ سب سے آسان OpenRouter ہے: ایک ہی کلید سے سب ماڈل
3. کوئی بھی صفحہ کھولیں اور سوال پوچھنا شروع کریں
