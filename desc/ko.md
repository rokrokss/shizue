🌸 Shizue는 크롬 사이드 패널에서 쓰는 AI 도우미입니다. 영상과 웹페이지를 원문과 번역을 함께 보며 즐기고, 탭에서 할 일을 맡기면 대신 클릭해 처리하고, 탭을 옮기지 않고 AI와 대화하고, 읽던 글을 한 번에 요약할 수 있습니다.

Shizue는 무료 오픈소스(MIT)입니다. ChatGPT로 로그인해 내 구독으로 쓰거나, 원하는 AI 제공업체에서 직접 발급받은 API 키로 쓰고 쓴 만큼만 비용을 낼 수 있습니다. 내 컴퓨터에서 실행하는 모델을 쓰면 키도 비용도 필요 없습니다. Shizue 자체에는 회원가입도 구독도 서버도 없습니다.


✨ 기능

🔐 ChatGPT 로그인
- 로그인만 하면 API 키 없이 지금 쓰는 구독으로 바로 쓸 수 있습니다

🎬 영상 이중 자막
- 유튜브: 영상을 보며 원문과 내 언어를 위아래로 함께 보고, A와 D 키로 이전·다음 줄로 이동합니다
- 트위치: 생방송과 다시보기에서 스트리머 자막이나 음성 인식을 바탕으로, 크롬이 기기 안에서 비용 없이 바로 옮겨 줍니다
- 넷플릭스: 작품에 내 언어 자막이 있으면 원문 아래에 함께 보여 주고, 없으면 재생보다 미리 옮겨 둡니다
- 디즈니+, 프라임 비디오, HBO Max, X, Udemy, Coursera, TED, Vimeo와 Google Meet, Microsoft Teams, Zoom 회의 실시간 자막에서도 씁니다

🕹️ 브라우저 조작
- 할 일을 말하면 Shizue가 탭에서 클릭하고, 입력하고, 고르고, 스크롤하며 한 단계씩 처리하고, 각 단계를 패널에 보여 줍니다
- 보내기, 삭제, 결제처럼 되돌리기 어려운 일은 먼저 묻고, 비밀번호와 카드 입력란에는 절대 입력하지 않습니다
- 페이지가 다른 사이트에서 불러온 예약, 문의, 결제 양식도 다룹니다
- 페이지 위 Shizue 메뉴 맨 위에서 바로 시작합니다

💬 사이드 패널 채팅
- 어디서든 Ctrl+Shift+E(Mac은 Cmd+Shift+E)로 엽니다
- 이미지를 첨부할 수 있고, 지난 대화는 기록에서 다시 열 수 있습니다

📋 페이지 요약
- 한 번에 요약을 받고, 그 내용으로 이어서 질문할 수 있습니다

🌐 웹페이지 이중 언어 번역
- 문단마다 바로 아래에 번역이 붙어서 원문을 그대로 보면서 읽을 수 있습니다

🎯 우클릭 메뉴
- 선택한 텍스트: 번역, 설명, 요약, 문법 교정
- 이미지: 내용 설명, 글자 추출, 이미지 번역. 만화와 웹툰은 페이지의 이미지를 한 번에 번역합니다
- 페이지 전체: 번역, 요약

📝 메모
- 입력하는 대로 자동 저장되고, 고정과 검색을 지원합니다

🎨 그 밖에
- 모델별 토큰 사용량 차트
- 라이트·다크 테마
- 23개 언어 인터페이스


🔒 개인정보
- 로그인 정보와 키, 대화 기록, 메모는 내 브라우저에만 저장됩니다
- 기능을 쓸 때 그 기능에 필요한 내용만 브라우저에서 내가 고른 AI 제공업체로 바로 전송됩니다
- 브라우저 조작은 작업하는 탭을 글자로만 읽습니다. 비밀번호와 카드 입력란은 읽지 않고, 화면을 캡처하지 않습니다
- 로컬 모델을 쓰면 아무것도 내 컴퓨터 밖으로 나가지 않습니다
- 분석이나 추적 도구를 쓰지 않습니다
- 소스 코드: https://github.com/rokrokss/shizue


🚀 시작하기
1. Shizue를 설치하고 Ctrl+Shift+E(Mac은 Cmd+Shift+E)로 사이드 패널을 엽니다
2. ChatGPT로 로그인하거나, API 키를 붙여 넣거나, 내 컴퓨터에서 실행 중인 모델을 연결합니다
3. 아무 사이트에서나 질문을 시작합니다
