🌸 Shizue - AI 기반 브라우징 어시스턴트

Shizue는 대규모 언어 모델(LLM)을 일상적인 웹 브라우징에 원활하게 통합하는 Chrome 확장 프로그램입니다. 직관적인 사이드 패널 인터페이스로 브라우저에서 직접 AI의 힘을 경험하세요.

✨ 주요 기능

🌐 스마트 이중언어 번역
- AI 기반 번역으로 두 언어로 동시에 콘텐츠 읽기
- 언어 학습자와 국제 콘텐츠 소비자에게 완벽
- 고급 LLM 이해로 문맥과 뉘앙스 보존

🎬 실시간 YouTube 자막 번역
- 즉각적인 AI 번역으로 모든 언어의 동영상 시청
- 시청하면서 자연스럽게 자막 표시
- 여러 대상 언어 지원

📝 웹 메모
- 브라우징 중 메모 작성
- 생각과 아이디어 정리
- 메모를 쉽게 검색
- 브라우징 세션 전반에 걸쳐 메모 접근

💬 대화형 AI 채팅 어시스턴트
- 웹페이지 콘텐츠에 대해 질문
- 즉각적인 요약, 설명, 통찰력 얻기
- 여러 AI 모델 지원 (OpenAI GPT, Claude, Gemini)
- 현재 페이지 기반 문맥 인식 응답

📋 원클릭 페이지 요약
- 모든 기사나 웹페이지의 주요 아이디어 즉시 파악
- 간결한 AI 생성 요약으로 시간 절약
- 연구 및 빠른 정보 수집에 완벽

🎯 스마트 컨텍스트 메뉴 액션
- 선택한 텍스트를 마우스 오른쪽 버튼으로 클릭하여 번역, 설명, 요약
- 문법 검사 및 글쓰기 개선 제안
- 페이지를 떠나지 않고 AI 기능에 빠르게 접근

🎨 추가 기능
- 편안한 보기를 위한 다크/라이트 테마 지원
- 24개 이상의 언어 지원
- 사용자 정의 가능한 키보드 단축키
- API 관리를 위한 토큰 사용량 추적

🚀 시작하기
1. Chrome 웹 스토어에서 Shizue 설치
2. 확장 프로그램 아이콘을 클릭하여 사이드 패널 열기
3. 선호하는 AI API 키 추가 (OpenAI, Anthropic 또는 Google)
4. AI 슈퍼파워로 브라우징 시작!

- 학생 및 연구자
- 언어 학습자
- 콘텐츠 크리에이터 및 작가
- 국제 전문가
- 더 스마트하게 브라우징하고 싶은 모든 사람
