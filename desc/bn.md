🌸 Shizue - আপনার AI-চালিত ব্রাউজিং সহায়ক

Shizue একটি Chrome এক্সটেনশন যা আপনার দৈনন্দিন ওয়েব ব্রাউজিংয়ে লার্জ ল্যাঙ্গুয়েজ মডেল (LLMs) সুন্দরভাবে একীভূত করে, যা অনলাইন কন্টেন্টের সাথে আপনার ইন্টারঅ্যাকশনের ধরন পরিবর্তন করে দেয়। আমাদের স্বজ্ঞাত সাইড প্যানেল ইন্টারফেসের মাধ্যমে সরাসরি আপনার ব্রাউজারে AI এর শক্তি অনুভব করুন।

✨ মূল বৈশিষ্ট্যসমূহ

🌐 স্মার্ট দ্বিভাষিক অনুবাদ
- AI-চালিত অনুবাদের সাথে একসাথে দুটি ভাষায় কন্টেন্ট পড়ুন
- ভাষা শিক্ষার্থী এবং আন্তর্জাতিক কন্টেন্ট ব্যবহারকারীদের জন্য নিখুঁত
- উন্নত LLM বোঝার সাথে প্রসঙ্গ এবং সূক্ষ্মতা সংরক্ষণ করে

🎬 রিয়েল-টাইম YouTube ক্যাপশন অনুবাদ
- তাৎক্ষণিক AI অনুবাদের সাথে যেকোনো ভাষায় ভিডিও দেখুন
- আপনি দেখার সাথে সাথে ক্যাপশনগুলি স্বাভাবিকভাবে প্রদর্শিত হয়
- একাধিক টার্গেট ভাষার জন্য সহায়তা

📄 লেআউট সংরক্ষণ সহ PDF অনুবাদ
- মূল ফরম্যাটিং বজায় রেখে সম্পূর্ণ PDF ডকুমেন্ট অনুবাদ করুন
- একাডেমিক পেপার, ম্যানুয়াল এবং অফিসিয়াল ডকুমেন্টের জন্য নিখুঁত
- অফলাইন ব্যবহারের জন্য অনুবাদিত PDF এক্সপোর্ট করুন

📝 ওয়েব মেমো
- ব্রাউজিং করার সময় নোট নিন
- আপনার চিন্তাভাবনা এবং ধারণাগুলি সংগঠিত করুন
- সহজেই আপনার মেমোগুলি অনুসন্ধান করুন
- ব্রাউজিং সেশন জুড়ে আপনার নোটগুলি অ্যাক্সেস করুন

💬 ইন্টারঅ্যাক্টিভ AI চ্যাট সহায়ক
- যেকোনো ওয়েবপেজ কন্টেন্ট সম্পর্কে প্রশ্ন করুন
- তাৎক্ষণিক সারাংশ, ব্যাখ্যা এবং অন্তর্দৃষ্টি পান
- একাধিক AI মডেল সমর্থন করে (OpenAI GPT-4, Claude, Gemini)
- বর্তমান পৃষ্ঠার উপর ভিত্তি করে প্রসঙ্গ-সচেতন প্রতিক্রিয়া

📋 এক-ক্লিক পৃষ্ঠা সারসংক্ষেপ
- যেকোনো নিবন্ধ বা ওয়েবপেজের মূল ধারণাগুলি তাৎক্ষণিকভাবে বুঝুন
- সংক্ষিপ্ত, AI-উৎপন্ন সারাংশের সাথে সময় বাঁচান
- গবেষণা এবং দ্রুত তথ্য সংগ্রহের জন্য নিখুঁত

🎯 স্মার্ট কনটেক্সট মেনু অ্যাকশন
- নির্বাচিত পাঠ্য অনুবাদ, ব্যাখ্যা বা সারসংক্ষেপ করতে ডান-ক্লিক করুন
- ব্যাকরণ পরীক্ষা এবং লেখার উন্নতির পরামর্শ
- পৃষ্ঠা ছাড়াই AI বৈশিষ্ট্যগুলিতে দ্রুত অ্যাক্সেস

🎨 অতিরিক্ত বৈশিষ্ট্য
- আরামদায়ক দেখার জন্য ডার্ক/লাইট থিম সমর্থন
- 24+ ভাষার জন্য সমর্থন
- কাস্টমাইজযোগ্য কীবোর্ড শর্টকাট
- গোপনীয়তা-কেন্দ্রিক: আপনার ডেটা স্থানীয় থাকে
- API ব্যবস্থাপনার জন্য টোকেন ব্যবহার ট্র্যাকিং
