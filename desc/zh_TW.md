🌸 Shizue 是在 Chrome 側邊欄中使用的 AI 助理，只要使用 ChatGPT 登入，不需要 API 金鑰就能用你的 ChatGPT 方案。不必切換分頁就能和 AI 對話，一鍵總結正在閱讀的內容，也能對照原文和譯文瀏覽網頁、觀看 YouTube 影片。

Shizue 是免費的開源軟體（MIT）。你也可以使用自備的 AI 供應商 API 金鑰，依實際用量付費；或使用在自己電腦上執行的模型，不需要金鑰，也不會產生費用。Shizue 本身不需要註冊帳號，沒有訂閱，也沒有伺服器。


✨ 功能

💬 側邊欄對話
- 隨時按 Ctrl+Shift+E（Mac 為 Cmd+Shift+E）即可開啟
- 可以上傳圖片，也能從歷史記錄回到先前的對話

📋 頁面總結
- 一鍵產生摘要，接著針對它繼續提問

🌐 網頁雙語對照
- 譯文顯示在每個段落下方，原文留在原處

🎬 YouTube 雙語字幕
- 一邊看影片一邊翻譯字幕，顯示在原字幕下方
- 可以選擇目標語言和字幕行數，按 A 或 D 鍵跳到上一句或下一句字幕

🎯 右鍵選單
- 所選文字：翻譯、解釋、總結、修正文法
- 圖片：描述內容、擷取文字
- 整個頁面：翻譯、總結

📝 備忘錄
- 輸入時自動儲存，支援置頂和搜尋

🎨 其他
- 依模型統計的 Token 用量圖表
- 淺色和深色主題
- 介面支援 23 種語言


🔒 隱私
- 登入資訊、API 金鑰、對話記錄和備忘錄只會儲存在瀏覽器中
- 使用某項功能時，只有該功能需要的內容會從瀏覽器直接傳送到所選的 AI 供應商
- 使用本機模型時，任何內容都不會離開你的電腦
- 不使用分析或追蹤工具
- 原始碼：https://github.com/rokrokss/shizue


🚀 開始使用
1. 安裝 Shizue，按 Ctrl+Shift+E（Mac 為 Cmd+Shift+E）開啟側邊欄
2. 使用 ChatGPT 登入、貼上你的 API 金鑰，或連接在自己電腦上執行的模型
3. 開啟任何網站，開始提問
