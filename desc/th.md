🌸 Shizue คือผู้ช่วย AI ที่ใช้งานในแผงด้านข้างของ Chrome และใช้กับแพ็กเกจ ChatGPT ของคุณได้เลย แค่ลงชื่อเข้าใช้ด้วย ChatGPT ไม่ต้องใช้คีย์ API แชทกับ AI ได้โดยไม่ต้องสลับแท็บ สรุปสิ่งที่กำลังอ่านได้ในคลิกเดียว และอ่านหน้าเว็บหรือดูวิดีโอ YouTube โดยเห็นทั้งต้นฉบับและคำแปลไปพร้อมกัน

Shizue ใช้งานฟรีและเป็นโอเพนซอร์ส (MIT) จะใช้คีย์ API ของคุณเองจากผู้ให้บริการ AI ที่คุณเลือกและจ่ายตามที่ใช้จริงเท่านั้นก็ได้ หรือใช้โมเดลที่รันบนคอมพิวเตอร์ของคุณเอง โดยไม่ต้องใช้คีย์และไม่มีค่าใช้จ่าย ตัว Shizue เองไม่ต้องสร้างบัญชี ไม่มีค่าสมาชิก และไม่มีเซิร์ฟเวอร์


✨ ฟีเจอร์

💬 แชทในแผงด้านข้าง
- เปิดได้จากทุกที่ด้วย Ctrl+Shift+E (Cmd+Shift+E บน Mac)
- แนบรูปภาพได้ และกลับไปเปิดแชทก่อนหน้าได้จากประวัติ

📋 สรุปหน้าเว็บ
- รับบทสรุปในคลิกเดียว แล้วถามต่อเกี่ยวกับเนื้อหานั้นได้เลย

🌐 หน้าเว็บสองภาษา
- คำแปลจะแสดงใต้แต่ละย่อหน้า ต้นฉบับจึงยังอยู่ที่เดิม

🎬 คำบรรยาย YouTube สองภาษา
- แปลคำบรรยายระหว่างดู และแสดงไว้ใต้บรรทัดต้นฉบับ
- เลือกภาษาเป้าหมายและจำนวนบรรทัดได้ กด A หรือ D เพื่อไปยังคำบรรยายก่อนหน้าหรือถัดไป

🎯 เมนูคลิกขวา
- ข้อความที่เลือก: แปล อธิบาย สรุป และแก้ไวยากรณ์
- รูปภาพ: อธิบายภาพและดึงข้อความจากภาพ
- ทั้งหน้า: แปลและสรุป

📝 บันทึก
- บันทึกอัตโนมัติระหว่างพิมพ์ ปักหมุดและค้นหาได้

🎨 อื่น ๆ
- กราฟการใช้โทเค็นแยกตามโมเดล
- ธีมสว่างและธีมมืด
- อินเทอร์เฟซรองรับ 23 ภาษา


🔒 ความเป็นส่วนตัว
- ข้อมูลการลงชื่อเข้าใช้ คีย์ API ประวัติแชท และบันทึก เก็บไว้ในเบราว์เซอร์เท่านั้น
- เมื่อใช้ฟีเจอร์ใด จะส่งเฉพาะเนื้อหาที่ฟีเจอร์นั้นต้องใช้ จากเบราว์เซอร์ตรงไปยังผู้ให้บริการ AI ที่เลือกไว้
- เมื่อใช้โมเดลในเครื่อง จะไม่มีข้อมูลใดออกไปนอกคอมพิวเตอร์ของคุณ
- ไม่มีระบบวิเคราะห์หรือติดตามการใช้งาน
- ซอร์สโค้ด: https://github.com/rokrokss/shizue


🚀 เริ่มต้นใช้งาน
1. ติดตั้ง Shizue แล้วกด Ctrl+Shift+E (Cmd+Shift+E บน Mac) เพื่อเปิดแผงด้านข้าง
2. ลงชื่อเข้าใช้ด้วย ChatGPT วางคีย์ API ของคุณ หรือเชื่อมต่อโมเดลที่รันอยู่บนคอมพิวเตอร์ของคุณ
3. เปิดเว็บไซต์ไหนก็ได้แล้วเริ่มถาม
