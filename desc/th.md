🌸 Shizue - ผู้ช่วยการท่องเว็บที่ขับเคลื่อนด้วย AI ของคุณ

Shizue เป็นส่วนขยาย Chrome ที่ผสานรวม Large Language Models (LLMs) เข้ากับการท่องเว็บประจำวันของคุณอย่างไร้รอยต่อ เปลี่ยนวิธีที่คุณโต้ตอบกับเนื้อหาออนไลน์ สัมผัสพลังของ AI โดยตรงในเบราว์เซอร์ของคุณด้วยอินเทอร์เฟซแผงด้านข้างที่ใช้งานง่าย

✨ คุณสมบัติหลัก

🌐 การแปลสองภาษาอัจฉริยะ
- อ่านเนื้อหาในสองภาษาพร้อมกันด้วยการแปลที่ขับเคลื่อนด้วย AI
- เหมาะสำหรับผู้เรียนภาษาและผู้บริโภคเนื้อหาระดับนานาชาติ
- รักษาบริบทและความละเอียดอ่อนด้วยความเข้าใจ LLM ขั้นสูง

🎬 การแปลคำบรรยาย YouTube แบบเรียลไทม์
- ดูวิดีโอในภาษาใดก็ได้ด้วยการแปล AI แบบทันที
- คำบรรยายปรากฏตามธรรมชาติขณะที่คุณดู
- รองรับหลายภาษาเป้าหมาย

📄 การแปล PDF พร้อมรักษาเลย์เอาต์
- แปลเอกสาร PDF ทั้งฉบับพร้อมรักษาการจัดรูปแบบเดิม
- เหมาะสำหรับเอกสารวิชาการ คู่มือ และเอกสารทางการ
- ส่งออก PDF ที่แปลแล้วสำหรับใช้งานออฟไลน์

📝 บันทึกเว็บ
- จดบันทึกขณะท่องเว็บ
- จัดระเบียบความคิดและไอเดียของคุณ
- ค้นหาในบันทึกของคุณได้ง่าย
- เข้าถึงบันทึกของคุณข้ามเซสชันการท่องเว็บ

💬 ผู้ช่วยแชท AI แบบโต้ตอบ
- ถามคำถามเกี่ยวกับเนื้อหาหน้าเว็บใดๆ
- รับสรุป คำอธิบาย และข้อมูลเชิงลึกทันที
- รองรับโมเดล AI หลายตัว (OpenAI GPT-4, Claude, Gemini)
- การตอบสนองที่คำนึงถึงบริบทตามหน้าปัจจุบัน

📋 สรุปหน้าด้วยคลิกเดียว
- เข้าใจแนวคิดหลักของบทความหรือหน้าเว็บใดๆ ได้ทันที
- ประหยัดเวลาด้วยสรุปกระชับที่สร้างโดย AI
- เหมาะสำหรับการวิจัยและรวบรวมข้อมูลอย่างรวดเร็ว

🎯 การดำเนินการเมนูบริบทอัจฉริยะ
- คลิกขวาเพื่อแปล อธิบาย หรือสรุปข้อความที่เลือก
- ตรวจสอบไวยากรณ์และข้อเสนอแนะการปรับปรุงการเขียน
- เข้าถึงคุณสมบัติ AI อย่างรวดเร็วโดยไม่ต้องออกจากหน้า

🎨 คุณสมบัติเพิ่มเติม
- รองรับธีมมืด/สว่างเพื่อการดูที่สบายตา
- รองรับมากกว่า 24 ภาษา
- ปรับแต่งทางลัดแป้นพิมพ์ได้
- เน้นความเป็นส่วนตัว: ข้อมูลของคุณยังคงอยู่ในเครื่อง
- ติดตามการใช้โทเค็นสำหรับการจัดการ API

🚀 เริ่มต้นใช้งาน
1. ติดตั้ง Shizue จาก Chrome Web Store
2. คลิกไอคอนส่วนขยายเพื่อเปิดแผงด้านข้าง
3. เพิ่มคีย์ AI API ที่คุณต้องการ (OpenAI, Anthropic หรือ Google)
4. เริ่มท่องเว็บด้วยพลังพิเศษของ AI!

💡 เหมาะสำหรับ
- นักเรียนและนักวิจัย
- ผู้เรียนภาษา
- ผู้สร้างเนื้อหาและนักเขียน
- มืออาชีพระดับนานาชาติ
- ทุกคนที่ต้องการท่องเว็บอย่างชาญฉลาด

🔒 ความเป็นส่วนตัวและความปลอดภัย
- คีย์ API เก็บไว้อย่างปลอดภัยในเบราว์เซอร์ของคุณ
- ไม่มีข้อมูลที่ส่งไปยังเซิร์ฟเวอร์บุคคลที่สาม (ยกเว้นผู้ให้บริการ AI ที่เลือก)

เปลี่ยนประสบการณ์การท่องเว็บของคุณด้วย Shizue - ที่ซึ่ง AI พบกับการใช้เว็บประจำวัน ติดตั้งตอนนี้และค้นพบวิธีที่ฉลาดกว่าในการสำรวจอินเทอร์เน็ต!
