🌸 Shizue คือผู้ช่วย AI ที่ใช้งานในแผงด้านข้างของ Chrome แชทกับ AI ได้โดยไม่ต้องออกจากหน้าที่เปิดอยู่ สรุปหน้าที่กำลังอ่านได้ในคลิกเดียว และอ่านหน้าเว็บหรือดูวิดีโอ YouTube โดยเห็นทั้งต้นฉบับและคำแปลไปพร้อมกัน

Shizue ใช้งานฟรีและเป็นโอเพนซอร์ส (MIT) ทำงานด้วยคีย์ API ของคุณเอง จะใช้คีย์ของ OpenAI, Anthropic (Claude), Google (Gemini) หรือใช้คีย์ OpenRouter คีย์เดียวสำหรับทุกโมเดลข้างต้นรวมถึง DeepSeek ก็ได้ ไม่ต้องสร้างบัญชี ไม่มีค่าสมาชิก และไม่มีเซิร์ฟเวอร์ของ Shizue จ่ายค่าใช้งานให้ผู้ให้บริการ AI ตามที่ใช้จริงเท่านั้น


✨ ฟีเจอร์

💬 แชทในแผงด้านข้าง
- เปิดได้จากทุกหน้าด้วย Ctrl+Shift+E (Cmd+Shift+E บน Mac)
- แนบรูปภาพได้ และกลับไปเปิดแชทก่อนหน้าได้จากประวัติ

📋 สรุปหน้าเว็บ
- สรุปหน้าที่กำลังอ่านในคลิกเดียว แล้วถามต่อในแชทเดิมได้เลย

🌐 หน้าเว็บสองภาษา
- คำแปลจะแสดงใต้แต่ละย่อหน้า ต้นฉบับจึงยังอยู่ที่เดิม

🎬 คำบรรยาย YouTube สองภาษา
- แปลคำบรรยายระหว่างดู และแสดงไว้ใต้บรรทัดต้นฉบับ
- เลือกภาษาเป้าหมายและจำนวนบรรทัดได้ กด A หรือ D เพื่อไปยังคำบรรยายก่อนหน้าหรือถัดไป

🎯 เมนูคลิกขวา
- ข้อความที่เลือก: แปล อธิบาย สรุป และแก้ไวยากรณ์
- รูปภาพ: อธิบายภาพและดึงข้อความจากภาพ
- ทั้งหน้า: แปลและสรุป

📝 บันทึก
- บันทึกอัตโนมัติระหว่างพิมพ์ ปักหมุดและค้นหาได้

🎨 อื่น ๆ
- กราฟการใช้โทเค็นแยกตามโมเดล
- ธีมสว่างและธีมมืด
- อินเทอร์เฟซรองรับ 23 ภาษา


🔒 ความเป็นส่วนตัว
- คีย์ API ประวัติแชท และบันทึก เก็บไว้ในเบราว์เซอร์เท่านั้น
- เมื่อใช้ฟีเจอร์ใด จะส่งเฉพาะเนื้อหาที่ฟีเจอร์นั้นต้องใช้ จากเบราว์เซอร์ตรงไปยังผู้ให้บริการ AI ที่เลือกไว้
- ไม่มีระบบวิเคราะห์หรือติดตามการใช้งาน
- ซอร์สโค้ด: https://github.com/rokrokss/shizue


🚀 เริ่มต้นใช้งาน
1. ติดตั้ง Shizue แล้วกด Ctrl+Shift+E (Cmd+Shift+E บน Mac) เพื่อเปิดแผงด้านข้าง
2. วางคีย์ API ใช้ OpenRouter ง่ายที่สุด เพราะคีย์เดียวใช้ได้ทุกโมเดล
3. เปิดหน้าไหนก็ได้แล้วเริ่มถาม
