🌸 Shizue 是在 Chrome 侧边栏中使用的 AI 助手。可以对照原文和译文观看视频、浏览网页，让 Shizue 在标签页里替你点击完成任务，不用切换标签页就能和 AI 聊天，还能一键总结正在阅读的内容。

Shizue 是免费的开源软件（MIT）。你可以使用 ChatGPT 登录，用自己的套餐；也可以使用自备的 AI 提供商 API 密钥，按实际用量付费。还可以使用在自己电脑上运行的模型，无需密钥，也不产生费用。Shizue 本身不需要注册账号，没有订阅，也没有服务器。


✨ 功能

🔐 使用 ChatGPT 登录
- 只需登录，无需 API 密钥即可使用你现有的套餐

🎬 视频双语字幕
- YouTube：边看边在原文下方显示你的语言字幕，按 A 或 D 键跳到上一句或下一句
- Twitch：直播和回放都支持，基于主播字幕或语音识别，由 Chrome 在本机免费翻译
- Netflix：作品带有你所用语言的字幕时，直接显示在原文下方；没有的话，会在播放前提前准备好

🕹️ 浏览器操作
- 告诉 Shizue 要做什么，它会在标签页中点击、输入、选择和滚动，一步一步完成，每一步都显示在侧边栏中
- 发送、删除或付款前会先征得你的同意，也绝不会在密码或银行卡输入框中输入
- 网页从其他网站嵌入的预订、联系和结账表单也能操作
- 从页面上 Shizue 菜单的最上方即可开始

💬 侧边栏聊天
- 随时按 Ctrl+Shift+E（Mac 上为 Cmd+Shift+E）打开
- 可以上传图片，也能从历史记录回到之前的聊天

📋 页面总结
- 一键生成摘要，然后围绕它继续提问

🌐 网页双语对照
- 译文显示在每个段落下方，原文保留在原处

🎯 右键菜单
- 所选文字：翻译、解释、总结、修正语法
- 图片：描述内容、提取文字、翻译图片。看漫画和条漫时，可以一次翻译页面上的所有图片
- 整个页面：翻译、总结

📝 备忘录
- 输入时自动保存，支持置顶和搜索

🎨 其他
- 按模型统计的 Token 用量图表
- 浅色和深色主题
- 界面支持 23 种语言


🔒 隐私
- 登录信息、密钥、聊天记录和备忘录只保存在浏览器中
- 使用某项功能时，只有该功能需要的内容会从浏览器直接发送到所选的 AI 提供商
- 浏览器操作只以文字形式读取所操作的标签页：不读取密码或银行卡输入框，也不截图
- 使用本地模型时，任何内容都不会离开你的电脑
- 不使用统计分析或追踪工具
- 源代码：https://github.com/rokrokss/shizue


🚀 开始使用
1. 安装 Shizue，按 Ctrl+Shift+E（Mac 上为 Cmd+Shift+E）打开侧边栏
2. 使用 ChatGPT 登录、粘贴你的 API 密钥，或连接在自己电脑上运行的模型
3. 打开任意网站，开始提问
