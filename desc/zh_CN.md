🌸 Shizue 是在 Chrome 侧边栏中使用的 AI 助手，只需使用 ChatGPT 登录，无需 API 密钥即可用你的 ChatGPT 套餐。不用切换标签页就能和 AI 聊天，一键总结正在阅读的内容，还能对照原文和译文浏览网页、观看 YouTube 视频。

Shizue 是免费的开源软件（MIT）。你也可以使用自备的 AI 提供商 API 密钥，按实际用量付费；或使用在自己电脑上运行的模型，无需密钥，也不产生费用。Shizue 本身不需要注册账号，没有订阅，也没有服务器。


✨ 功能

💬 侧边栏聊天
- 随时按 Ctrl+Shift+E（Mac 上为 Cmd+Shift+E）打开
- 可以上传图片，也能从历史记录回到之前的聊天

📋 页面总结
- 一键生成摘要，然后围绕它继续提问

🌐 网页双语对照
- 译文显示在每个段落下方，原文保留在原处

🎬 YouTube 双语字幕
- 边看视频边翻译字幕，显示在原字幕下方
- 可以选择目标语言和字幕行数，按 A 或 D 键跳到上一条或下一条字幕

🎯 右键菜单
- 所选文字：翻译、解释、总结、修正语法
- 图片：描述内容、提取文字
- 整个页面：翻译、总结

📝 备忘录
- 输入时自动保存，支持置顶和搜索

🎨 其他
- 按模型统计的 Token 用量图表
- 浅色和深色主题
- 界面支持 23 种语言


🔒 隐私
- 登录信息、API 密钥、聊天记录和备忘录只保存在浏览器中
- 使用某项功能时，只有该功能需要的内容会从浏览器直接发送到所选的 AI 提供商
- 使用本地模型时，任何内容都不会离开你的电脑
- 不使用统计分析或追踪工具
- 源代码：https://github.com/rokrokss/shizue


🚀 开始使用
1. 安装 Shizue，按 Ctrl+Shift+E（Mac 上为 Cmd+Shift+E）打开侧边栏
2. 使用 ChatGPT 登录、粘贴你的 API 密钥，或连接在自己电脑上运行的模型
3. 打开任意网站，开始提问
