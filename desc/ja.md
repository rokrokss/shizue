🌸 Shizue - AIパワード・ブラウジング・アシスタント

Shizueは、大規模言語モデル（LLM）を日常のウェブブラウジングにシームレスに統合するChrome拡張機能です。直感的なサイドパネルインターフェースで、ブラウザで直接AIの力を体験してください。

✨ 主な機能

🌐 スマートバイリンガル翻訳
- AI搭載の翻訳で2つの言語で同時にコンテンツを読む
- 高度なLLM理解でコンテキストとニュアンスを保持

🎬 リアルタイムYouTubeキャプション翻訳
- 瞬時のAI翻訳であらゆる言語の動画を視聴
- 視聴中に自然にキャプションが表示される
- 複数のターゲット言語をサポート

📝 ウェブメモ
- ブラウジング中にメモを取る
- 考えやアイデアを整理する
- メモを簡単に検索
- ブラウジングセッション全体でメモにアクセス

💬 インタラクティブAIチャットアシスタント
- ウェブページのコンテンツについて質問
- 即座に要約、説明、洞察を得る
- 複数のAIモデルをサポート（OpenAI GPT、Claude、Gemini）
- 現在のページに基づくコンテキスト対応の応答

📋 ワンクリックページ要約
- あらゆる記事やウェブページの主要なアイデアを即座に把握
- 簡潔なAI生成の要約で時間を節約

🎯 スマートコンテキストメニューアクション
- 選択したテキストを右クリックして翻訳、説明、要約
- 文法チェックと文章改善の提案
- ページを離れることなくAI機能に素早くアクセス

🎨 追加機能
- 快適な表示のためのダーク/ライトテーマサポート
- 24以上の言語をサポート
- カスタマイズ可能なキーボードショートカット
- API管理のためのトークン使用状況追跡

🚀 はじめに
1. Chrome Web StoreからShizueをインストール
2. 拡張機能アイコンをクリックしてサイドパネルを開く
3. お好みのAI APIキー（OpenAI、Anthropic、またはGoogle）を追加
4. AIのスーパーパワーでブラウジングを開始！

🔒 プライバシーとセキュリティ
- APIキーはブラウザに安全に保存
- サードパーティサーバーにデータを送信しない（選択したAIプロバイダーを除く）
