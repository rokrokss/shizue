🌸 Shizue - Ваш помощник для просмотра веб-страниц на базе ИИ

Shizue - это расширение Chrome, которое органично интегрирует большие языковые модели (LLM) в ваш ежедневный веб-серфинг, преобразуя способ вашего взаимодействия с онлайн-контентом. Испытайте мощь ИИ прямо в вашем браузере с нашим интуитивным интерфейсом боковой панели.

✨ Основные функции

🌐 Интеллектуальный двуязычный перевод
- Читайте контент на двух языках одновременно с переводом на основе ИИ
- Сохраняет контекст и нюансы благодаря продвинутому пониманию LLM

🎬 Перевод субтитров YouTube в реальном времени
- Смотрите видео на любом языке с мгновенными переводами ИИ
- Субтитры появляются естественно во время просмотра
- Поддержка нескольких целевых языков

📝 Веб-заметки
- Делайте заметки во время просмотра
- Организуйте свои мысли и идеи
- Легко ищите в своих заметках
- Получайте доступ к заметкам между сеансами просмотра

💬 Интерактивный ИИ-чат помощник
- Задавайте вопросы о любом содержимом веб-страницы
- Получайте мгновенные резюме, объяснения и идеи
- Поддерживает несколько моделей ИИ (OpenAI GPT, Claude, Gemini)
- Ответы с учетом контекста на основе текущей страницы

📋 Резюме страницы одним кликом
- Мгновенно поймите основные идеи любой статьи или веб-страницы
- Экономьте время с краткими резюме, созданными ИИ

🎯 Умные действия контекстного меню
- Правый клик для перевода, объяснения или резюмирования выделенного текста
- Проверка грамматики и предложения по улучшению письма
- Быстрый доступ к функциям ИИ без покидания страницы

🎨 Дополнительные функции
- Поддержка темной/светлой темы для комфортного просмотра
- Поддержка более 24 языков
- Настраиваемые сочетания клавиш
- Отслеживание использования токенов для управления API

🚀 Начало работы
1. Установите Shizue из Chrome Web Store
2. Нажмите на значок расширения, чтобы открыть боковую панель
3. Добавьте предпочитаемый ключ API ИИ (OpenAI, Anthropic или Google)
4. Начните просмотр с суперспособностями ИИ!

🔒 Конфиденциальность и безопасность
- Ключи API надежно хранятся в вашем браузере
- Никакие данные не отправляются на сторонние серверы (кроме выбранных поставщиков ИИ)
