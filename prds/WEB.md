## 개요
Shizue Chrome 익스텐션의 가치를 효과적으로 전달하고 다운로드를 유도하는 웹 애플리케이션을 구축합니다. shizue.ai 도메인을 통해 서비스의 핵심 기능과 차별점을 시각적으로 매력적인 홍보 페이지로 제공합니다.

### 핵심 요구사항
- shizue.ai 도메인에서 접근 가능한 반응형 웹 애플리케이션
- Shizue 익스텐션의 핵심 기능을 시각적으로 보여주는 랜딩 페이지
- Chrome 웹스토어로의 효과적인 다운로드 유도 (CTA)
- 향후 웹 기반 서비스 확장을 고려한 확장 가능한 아키텍처
- 전체 23개 언어 지원 (ar, bn, de, en, es, fa, fil, fr, hi, it, ja, ko, pl, pt_BR, pt_PT, ru, sw, th, tr, ur, vi, zh_CN, zh_TW)

### 영향받는 컴포넌트
- [x] Frontend (React/Next.js 웹 애플리케이션)
- [ ] Backend API (향후 확장용)
- [ ] CDN/정적 호스팅 서비스
- [ ] 분석 도구 (Google Analytics 등)
- [ ] SEO 최적화

## 배경 및 목표

### 문제 정의
현재 Shizue는 Chrome 웹스토어에서만 발견할 수 있으며, 잠재 사용자들이 서비스의 가치를 충분히 이해하기 어렵습니다. 경쟁 서비스(Sider 등)와 달리 무료 오픈소스이며 사용자가 자신의 API 키를 사용할 수 있다는 핵심 차별점이 충분히 전달되지 않고 있습니다.

### 사용자 스토리
- As a **potential user**, I want to **understand what Shizue does and why it's better than alternatives** so that **I can decide to install it**
- As a **privacy-conscious user**, I want to **know that my data is secure and I control my API keys** so that **I can trust the service**
- As a **multilingual user**, I want to **see the features in my native language** so that **I can fully understand the value proposition**

### 성공 지표
- [ ] 웹사이트 방문자의 Chrome 웹스토어 클릭률 > 15%
- [ ] 페이지 로딩 시간 < 2초 (LCP)
- [ ] 모바일 친화성 점수 > 95점
- [ ] SEO 점수 > 90점 (Lighthouse 기준)
- [ ] 다국어 사용자 참여율 균등 분포

## 기술 사양

### 기술 스택
- **Frontend Framework**: Next.js 14+ (App Router)
- **스타일링**: Tailwind CSS v4 + shadcn/ui 컴포넌트
- **애니메이션**: Framer Motion
- **다국어**: next-i18next
- **호스팅**: Vercel 또는 Netlify
- **분석**: Google Analytics 4 + Vercel Analytics

### 프로젝트 구조
```
webapp/
├── app/
│   ├── [locale]/
│   │   ├── page.tsx          # 메인 홍보 페이지
│   │   ├── layout.tsx        # 루트 레이아웃
│   │   └── features/         # 기능별 상세 페이지 (향후)
│   ├── api/                  # API 라우트 (향후)
│   └── components/
│       ├── Header/           # 헤더 네비게이션
│       ├── Hero/             # 히어로 섹션
│       ├── Features/         # 기능 소개 섹션
│       ├── Platforms/        # 플랫폼 지원 섹션
│       ├── AIModels/         # AI 모델 소개
│       ├── HowItWorks/       # 작동 방식 설명
│       ├── Comparison/       # 경쟁사 비교
│       ├── Testimonials/     # 사용자 후기
│       ├── FAQ/              # 자주 묻는 질문
│       ├── CTA/              # 다운로드 유도
│       └── Footer/           # 푸터
├── public/
│   ├── images/              # 스크린샷, 데모 GIF
│   ├── icons/               # 기능 아이콘, 로고
│   └── locales/             # 번역 파일 (23개 언어)
├── styles/
│   └── globals.css          # 전역 스타일
└── lib/
    ├── analytics.ts         # 분석 유틸리티
    └── i18n.ts             # 다국어 설정
```
