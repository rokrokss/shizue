FAQ

Is it really free?

Yes, and it will stay free. You pay your AI provider (or OpenRouter) directly for the API calls you make, and the Token Usage chart shows how many tokens each model used.

What leaves my browser?

Only the content a feature needs, such as the page text for a summary, sent straight from your browser to the provider you chose. There is no Shizue server and no analytics. See the privacy policy.

Which key should I get?

The simplest is one OpenRouter key: it unlocks every model in Shizue, including DeepSeek. If you already have an OpenAI, Anthropic, or Gemini key, that works too.

Does it support local models or Firefox?

Not yet. Follow the GitHub repository for updates.
